## Bugs and questions

Open a GitHub issue on this repo. Use the bug or feature templates when they
fit. This is a side project — expect a reply in days, not hours.

## Security

Do not file public issues for vulnerabilities. See [SECURITY.md](SECURITY.md)
and use **Security → Report a vulnerability**.
